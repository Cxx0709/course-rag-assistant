# 证据可回答性筛选 v3（2026-10-23）

## 本轮结果

在与 v2 完全相同的 30 道可回答题和 10 道不可回答题上，离线证据筛选将 BM25/混合模式的拒答率从 0/10 提升到 10/10；纯向量从 5/10 提升到 10/10。同时三种模式均拒答了 2/30 道本应可回答的问题。项目仍未通过完整的问答质量验收。

| 模式 | 不可回答题拒答（v2 → v3） | 可回答题拒答（v2 → v3） | 答案点字面覆盖（v2 → v3） | 金标准页引用精确率（v2 → v3） |
|---|---|---|---|---|
| BM25 | 0/10 → 10/10 | 0/30 → 2/30 | 40.56% → 48.89% | 37.74% → 55.88% |
| 纯向量 | 5/10 → 10/10 | 0/30 → 2/30 | 25.00% → 38.89% | 31.74% → 40.96% |
| 混合 | 0/10 → 10/10 | 0/30 → 2/30 | 49.44% → 49.44% | 51.75% → 52.89% |

检索本身未修改，Recall@8 仍分别为 73.33%、70.00%、76.67%。拒答计入答案点覆盖的分母，没有通过移除被拒答题抬高覆盖率。没有输出引用时，引用精确率记作 `null`，而非 100%。

逐题结果：`eval/reports/quality-v3.json`。旧报告 `eval/reports/quality-v2.json` 保留用于比较。

## 实现

`src/course_rag_assistant/evidence.py` 在生成前筛选候选证据：

1. 去除常见问法词，对剩余问题词项计算正文覆盖率。使用固定的 0.5 开发阈值；只匹配标题或共享一个泛化词不再足够。
2. 对规则识别出的个人实验值、课程安排、分组或私人数据集统计问题，要求文件名或章节标题明确表示对应记录类型，例如“实验记录”“课程通知”“分组名单”“数据集清单”。教材中的类似数值不能直接作为个人记录。
3. 一般知识解释和学习建议不要求个人记录；“我想了解自动微分”和“我们如何提高模型准确率”可以使用课程证据。
4. 按原检索顺序保留通过筛选的候选，再进入已有的原文摘录与引用校验。筛选失败时不调用生成器。

返回的 `CitedAnswer` 新增可选 `abstention_reason`，保留原有三个位置参数兼容性。批量问答及质量报告会输出此字段：

| 原因 | 含义 |
|---|---|
| `no_evidence` | 没有可用候选证据 |
| `unclear_question` | 去掉问法词后没有明确检索对象 |
| `insufficient_query_coverage` | 候选正文不足以覆盖问题内容 |
| `missing_context_record` | 缺少相应个人记录或课程安排类型的出处 |
| `unsupported_citations` | 生成结果没有通过引用校验 |

未生成答案时不再把问题本身计作“不受支持的断言”。

本次 10 道负例中，4 道因正文覆盖不足被拒答，6 道因缺少对应记录被拒答。43 项测试通过，新增 16 项行为测试覆盖：同主题但缺少个人事实、提供对应记录后可回答、仅有记录标题仍不够、第一人称一般提问、学习建议、首位噪声候选和拒答时不调用生成器。

## 两道可回答题被拒答

- `d2l-v2-24`：线性回归示例中 `nn.Linear` 的两个参数各指定什么？三档检索都没有在前 8 个 chunk 中命中选定参考页 120，候选正文覆盖不足。需要同时改善检索和代码术语匹配。
- `d2l-v2-28`：ReLU 在负输入和正输入处的导数分别是多少？参考页已经进入检索结果，但“负输入”与“输入为负”等词序变化导致中文二元词匹配不足。这是筛选规则造成的误拒，说明不能把当前阈值视作成熟的语义判断。

## 限制

- 这些题已参与开发和失败分析，不是独立保留测试集。10/10 仅是这一小批开发题的结果；不能据此宣称通用拒答率为 100%。
- 固定词表、正则和覆盖阈值是保守的中文离线启发式，可能误拒同义转述，也可能接受词汇相近却缺少答案的段落。
- 记录类型由文件名/章节推断，不能验证所有者、日期、实际测量值或多个记录之间的冲突。没有明确标题的真实日志也可能被误拒；后续应使用结构化来源元数据与语义证据判断。
- 一般解释/建议的识别也是启发式，不能涵盖所有语序和含糊指代。当前没有完整的对话指代消解。
- 字面答案点覆盖和页级引用精确率仍不等于事实正确率。重排、自由转述的语义校验和聊天模型端到端评测仍待完成。

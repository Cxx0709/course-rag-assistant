# 真实教材质量验收 v2（2026-10-23）

## 结论

本轮完成了可复现的开发集评测，但**问答质量尚未通过验收**。混合检索在选定参考页上优于 BM25 与纯向量；引用页命中、答案覆盖和拒答仍有明显缺口。尚未配置真正的 BGE 重排服务，不能声称完成四档消融。

## 数据与口径

- 本地语料：`data/raw/datamining-notes/d2l-zh-pytorch.pdf`，797 个物理页，当前解析为 3,760 个 chunk。
- `eval/real-questions-v2.jsonl`：30 题，覆盖定义、比较、公式和应用。每题包含物理页码、答案点和可在原页定位的证据摘录；跨页比较保留多个出处。
- `eval/real-unanswerable-v2.jsonl`：10 题，覆盖课程外问题、缺失个人信息、缺失实验记录。原来的 3 道样例不可回答题不能直接用于真实教材：其中的深度学习、pandas 等主题实际上被本教材收录。
- 新版题集保留了原有主题，并修正 softmax、MLP、RNN 等题的出处/表述。旧版题集及旧报告保留，历史指标不能与 v2 直接作纵向比较。
- 标注由代理核对 PDF 文本，并抽查页图；尚未经独立人工审核。它是开发集，不能作为未见测试集宣称泛化效果。题目集中在基础章节，后续还需要增加复杂、多跳和跨资料问题。
- 金标准页是选定的支持证据，不是所有相关页的穷举。未命中选定参考页不必然意味着检索结果无关；复核时应区分标签不完整与真正的检索失败。

## 实测结果

生成方式统一为离线原文摘录，未调用聊天模型；向量为本机 Ollama `bge-m3:latest`。所有模式使用同一批题、同一语料，k=8。

| 配置 | Recall@8 | MRR@8 | 答案点字面覆盖 | 金标准页引用精确率 | 不可回答题拒答率 |
|---|---:|---:|---:|---:|---:|
| BM25 | 73.33% | 0.4722 | 40.56% | 37.74% | 0/10 |
| 纯向量 | 70.00% | 0.3653 | 25.00% | 31.74% | 5/10 |
| 混合检索 | 76.67% | 0.5483 | 49.44% | 51.75% | 0/10 |
| 混合 + BGE 重排 | 未运行 | 未运行 | 未运行 | 未运行 | 未运行 |

30 道可回答题在三种配置中均没有拒答。该结果只能说明没有发生整题拒答，不能说明答案正确。

指标解释：

- Recall 按每题参考页集合计算后宏平均；MRR 截断在前 8 个 chunk，重复页不折叠。
- 答案点覆盖只检测去空白后的字面包含，不等于语义正确率；同义改写和公式符号变化会影响结果。
- 引用精确率的分母为输出中的引用次数，分子为指向金标准页的次数。它比“答案是否带引用”更严格，但仍不是断言蕴含判断。
- 不可回答题的非拒答属于“证据不足仍作答”；原文摘录可能真实，因此不能全部标成幻觉。原评测字段 `hallucinated` 已更名为 `non_abstained`。
- 报告耗时包含检索、答案和拒答评测，不包含语料解析、首次问题向量生成，也不是在线单次问答延迟。

## 失败案例与含义

1. **课程外问题仍能获得引用。** “如何办理护照首次申请？”在 BM25/混合模式下命中云服务器申请/限制内容。局部词语重合并不能提供回答护照问题所需的证据。
2. **个人实验数据缺失未被识别。** “我昨天训练的卷积神经网络测试准确率是多少？”返回教材里的 CNN 内容。课程主题相关，不代表教材知道用户的实验结果。
3. **目录和代码干扰。** MLP 结构、`nn.Linear` 参数等问题的排名中出现目录、实现代码和其他网络章节，需要进一步检查切分、标题识别及重排。
4. **参考页不完整也会造成扣分。** 过拟合、梯度下降等概念在多个章节重复出现。当前参考页选自引言，后续章节命中可能仍然有价值；应由人工补充可接受出处，而非仅为提高分数替换金标准。
5. **检索命中不等于答案完整。** 当前离线回答只摘录第一个可用 chunk，而评测检索前 8 个 chunk；因此混合检索 76.67% 的参考页召回没有转化为相应的答案覆盖。

## 本轮校验修复

- 去掉“共享一个汉字即可通过”的引用判断；离线校验改为要求完整原文句子匹配，仅忽略空白。高词汇重合的反义断言、无证据的自由转述都会被拒绝。
- 逐句绑定引用，阻止后一句借用前一句引用；同一句混入不存在的引用也不予通过。
- 修复无标题 Markdown 的 `section=document` 引用无法解析的问题。
- 不再仅凭正的融合分数作答，至少检查问题与证据是否有词项交集。但本轮结果明确说明，这个最低门槛不足以实现可靠拒答。
- 保留已有的生成服务异常回退。生成提示改为选择并摘录原文句子；当前自由改写能力因此受到限制，需要后续语义校验才能恢复。

这些修复证明的是“文本能回溯到来源”，不保证来源回答了问题，也不保证教材本身的事实正确。27 项自动测试通过，包括反义断言、伪造出处、引用串用、空证据、页级评分反例。

## 复现

在项目根目录，首次生成问题向量：

```powershell
$env:COURSE_RAG_OLLAMA_MODEL="bge-m3:latest"
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_quality.py --dense
```

后续同一模型和题集可复用 `data/index/quality-query-v2.npy` 与配套 JSON，不需要模型服务运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_quality.py --dense
```

不使用向量的独立基线：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_quality.py --output eval/reports/quality-v2-bm25.json
```

脚本会验证每条摘录是否存在于原 PDF 页、当前 chunk 是否与向量索引一致，并记录代码、标签、语料、索引和问题向量的 SHA256。真实 PDF 和向量缓存仍在忽略目录中，复现者需要相同文件。结果及逐题详情见 `eval/reports/quality-v2.json`。

## 下一轮优先级

1. 建立问题可回答性判断，重点覆盖“主题相关但事实缺失”的反例；与可回答题的误拒率一同验收。
2. 人工复核金标准并另建保留测试集，避免在这 30 题上调整规则后将同一结果当成泛化指标。
3. 清理目录/代码噪声、改善切分与多证据答案组织，接入真正重排并补齐四档对比。
4. 在上述质量门槛明确后补交互页面及课程先修知识能力。

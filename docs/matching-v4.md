## 修改与依据

- **PDF 换行**：只在匹配阶段合并中文词内部的实际换行，保留普通空格，避免把问句清理后的分隔符重新粘连。原始 chunk、页码和向量索引保持一致。
- **词序**：对“负输入／输入为负”等有限的形容词/谓语形式做相同规范化，覆盖输入、输出、梯度、权重、数值。正负不会合并，也不删除否定词。它不是通用同义改写能力。
- **代码标识符**：将限定名称（如 `nn.Linear`）作为完整词项保留；检索时优先考虑包含该标识符且覆盖问题上下文的正文，避免大量重复调用的短代码片段压过解释性段落。规则也作用于混合检索候选合并之后。
- **证据约束**：明确问及某个限定 API 名称时，证据必须包含该名称；不能拿同一命名空间中的其他 API 代答。缺失时返回 `missing_code_identifier`。
- **输出断句**：合并原文中的中文行内断行后再绑定引用，避免在“指定”等词中间插入引用。原文校验使用相同断句规则，仍只允许忽略空白后的源句摘录。
- **索引兼容**：保存分词器版本，旧 BM25 索引加载时从原始 chunk 重建词项，避免新旧分词混用。向量索引不需重建。
- **评测性能**：BM25 词频在构建索引时缓存，避免每个问题重复统计；评分公式不变。

`nn.Linear` 参数题的第 120 物理页在 BM25/混合模式中均排名第一，答案包含输入特征形状和输出特征形状。ReLU 题三种模式均能通过证据筛选，返回负输入导数 0、正输入导数 1 的原文。纯向量的 `nn.Linear` 题仍拒答，因为原有前 8 条候选不足以支持完整答案。

# 同义名称与并列枚举

完成日期：2026-11-06。

本轮完成术语身份去重和带数量对应关系的枚举提取。D2L 8.3 从零题变为三道基础原文识记题；另选的三个章节仍全部零题，**通用质量与覆盖验收尚未通过**。

## 实现

`quiz_terms.py` 区分两种结构：

- **同义名称**：定义前用“又称／也称为／亦称／也叫做”明确连接的名称共享身份，英文名称也保留为别名。原文中的同义声明只在同一资料和已识别章节内传播；无编号章节时再限制到相同标题。题目隐藏同义名称，选项与题目列表都去重。裸露的“或”“和”、否定以及有条件的命名不被自动判为同义。
- **并列枚举**：完整句中数量与术语明确“分别”对应，且成员数相同、名称和数量没有重复时，按原顺序构造题目。共同的“模型／方法”等类别留在题干中；英文名称从题干隐藏，完整原文仍用于评分。条件、否定、顺序和共同范围不因拆分而丢弃。

同义身份用于防止泄题、重复题和不恰当选项；这轮没有扩展按概念筛选、评分或复习接口的名称匹配语义。简称、条件性别名、定义后才出现的别名等仍有未覆盖形式。

还收紧了原文类别识别：定义后的附带句提到“参数”，不能据此把一个误差概念归为参数。类别说明要求在定义的同一分句中明确出现。

## 教材结果与局限

PDF 323 页的原句将一个、两个、三个变量的概率公式分别对应到一元、二元、三元语法模型。页面渲染已查看，三题完整原句已逐字核对（忽略换行空白）。各题保留“通常”、变量数量及“模型”类别，选项来自原文三个名称。

这些题是**同一条对应关系的三种展开**，名称中的数字也让答案较容易判断；不能把三题视为三份独立教学证据，或据此声称理解了概率分解、马尔可夫假设或语言模型。此次不将其单独宣称为教学质量通过。

已有 4.4 四题、6.1 两题、6.2 一题、8.1 两题、9.2 两题仍保留。其他已知不足章节继续明确提示不足，见[教材回归报告](../eval/reports/quiz-terms-v1.json)。同义身份功能主要由有明确声明的测试样例验证，没有声称此前教材中的所有别名形式已被修复。

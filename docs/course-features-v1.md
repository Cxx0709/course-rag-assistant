## 修复内容

- PDF 软换行：句子切分时会连接换行，原先直接用子串比较会误丢完整句子。现在将候选映射回原文字符区间，显示时保留原始换行，引用仍指向原页。
- 英文撇号：单词内部的弯撇号不再在对比模块中被当作未闭合引号。仅在内部切句时处理，最终摘录恢复原字形；真正未闭合的引文仍被拒绝。
- 显式英文括注：中文概念标题后附括号英文名时可以匹配，例如“暂退法（Dropout）”。没有新增任意同义词推断。
- 概念主语：补充“由、在、通过、沿、用于”等直接陈述的识别，仍保留“独立”和“条件独立”等相似名称的边界。

修复均在对比模块内完成，没有修改现有语料、向量索引或问答模块的切句逻辑。

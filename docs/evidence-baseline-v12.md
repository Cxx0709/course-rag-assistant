# v12：证据完整性、固定基线与原文练习

本轮把引用约束和去重规则统一到所有回答模式，建立可失败退出的固定回归基线，并接入原文识记练习与错题复习清单。基线属于既有开发集回归，不代表通过独立语义质量验收。

## 引用与摘录修复

- 每一个附带引用都必须支持对应的完整原句。此前只要其中一个引用支持原句，另一个已存在但无关的引用也可能通过；现在整条断言会被拒绝。
- 普通模型选句、聊天重排选句和离线／故障回退都去除仅空白不同的相同原句，保留首选来源和回答顺序。带否定、条件或不同过程的相似句不会因相似度而被删除。
- 中文闭引号留在原句中，多句引语作为整体保留，PDF 引号缺失时不作为完整摘录。英文句号可以分句，同时保护小数、常见称谓缩写及限定 API 名称；完整代码中的句号不会被当作句子边界。
- 不跨页补写或猜测残缺原文。原有括号、控制字符和 PDF 残缺片段检查继续生效。

模型路径最多输出六条去重后的候选。离线模式继续输出首个合格片段中的完整原句，不使用六句硬截断：初次尝试截断会使答案点覆盖率从 67.78% 降至 52.78%，因此没有保留该策略。

这些都是结构与原文一致性约束。它们不等于语义相关性、教材事实正确性或回答全面性。资料本身出现矛盾时，普通概念回答暂不会自动判别矛盾。

## 固定基线

清单为 [baseline-v12-manifest.json](../eval/baseline-v12-manifest.json)，冻结既有 30 道可回答题、10 道不可回答题、PDF 语料、向量索引及查询缓存的 SHA-256，同时冻结既有两组验证集及新增的 12 个证据完整性案例。题目、参考页和答案点均没有为本轮结果修改。新增案例由开发代理编写，只能作为开发回归。

从项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m scripts.evaluate_baseline
```

默认连续运行两次离线混合检索与回答；比较逐题答案、选句编号、拒答原因和检索指标，排除计时差异。数据指纹变化会在评测前报错。预测不稳定、出现重复、证据完整性案例失败、正例被拒答、负例未拒答，或指标低于门槛，都会以非零状态退出。清单需要本机已有的原始 PDF、索引和查询缓存；缺失或重建后指纹不同会失败，不会静默改换评测配置。

回归门槛沿用先前离线 hybrid 成绩的保守下限：Recall@8 ≥ 83%、字面答案点覆盖率 ≥ 67%、参考页引用精度 ≥ 56%。这些不是产品质量验收目标，也不应用于聊天模型模式。

最终离线基线：[baseline-v12.json](../eval/reports/baseline-v12.json)。结果如下：

| 指标 | 离线 hybrid |
| --- | ---: |
| Recall@8 | 83.33% |
| MRR@8 | 62.81% |
| 字面答案点覆盖率 | 67.78% |
| 参考页引用精度 | 56.82% |
| 可回答题拒答 | 0 / 30 |
| 不可回答题拒答 | 10 / 10 |
| 已输出断言的完整原句支持率 | 100% |
| 重复原句数 | 0 |
| 固定证据完整性案例 | 12 / 12 |
| 两次逐题结果一致 | 是 |

原句支持率只说明输出可以逐字落到所引来源；参考页精度只比较已有标签中的参考页，标签并非穷尽所有相关页面。两者均不应写成语义正确率。未输出任何断言的空回答不会让本轮正例通过，因为基线同时要求正例零拒答和最低覆盖率。

## 模型实测

使用同一个本地 `qwen3.5:9b`、温度 0、16384 上下文、512 输出 token 与 `think=false`，分别执行 hybrid 与 hybrid+chat-rerank。最终报告为 [quality-v12-chat.json](../eval/reports/quality-v12-chat.json)，保留逐题输出、原始模型选句、引用证据和故障回退记录。

```powershell
$env:COURSE_RAG_OLLAMA_CHAT_MODEL="qwen3.5:9b"
$env:COURSE_RAG_OLLAMA_CHAT_NUM_CTX="16384"
$env:COURSE_RAG_OLLAMA_CHAT_NUM_PREDICT="512"
$env:NO_PROXY="127.0.0.1,localhost"
.\.venv\Scripts\python.exe scripts/evaluate_quality.py --dense --chat --chat-rerank --modes hybrid hybrid+chat-rerank --output eval/reports/quality-v12-chat.json
```

修复完善前的 [初测](../eval/reports/quality-v12-chat-first-pass.json) 保留为诊断记录，不作为最终代码验收。温度 0 也不保证模型选句与重排跨次完全一致；稳定性承诺仅适用于固定输入、缓存向量的离线基线。

最终模型实测与历史 v11 对比如下：

| 指标 | v11 hybrid | v12 hybrid | v11 聊天重排 | v12 聊天重排 |
| --- | ---: | ---: | ---: | ---: |
| 字面答案点覆盖率 | 82.22% | 78.89% | 78.61% | 78.61% |
| 参考页引用精度 | 60.00% | 57.14% | 54.22% | 53.66% |
| 可回答题拒答 | 0 / 30 | 0 / 30 | 0 / 30 | 0 / 30 |
| 不可回答题拒答 | 10 / 10 | 10 / 10 | 10 / 10 | 10 / 10 |

v12 两种模型模式的完整原句支持率均为 100%，重复原句均为 0，答案生成故障均为 0；聊天重排 40 次段落选择没有异常回退。最终模型报告与交付代码的所有记录指纹一致。

本轮没有提高参考页精度或整体答案点覆盖率。模型重排／选句和分句边界均可能影响结果，没有通过完全固定模型选择的回放将这些影响隔离，因此不把变化全部归因于结构修复。聊天重排继续保持可选；后续需要独立人工相关性判断和语义选句优化，不能把“原文支持率 100%”写成“答案准确率 100%”。

## Quiz 与错题定位

网页“练一练”从所选资料的完整原文句子生成概念填空选择题，提交后给出正确概念、完整原句、文件与页码／章节链接。生成不调用模型，不发送资料到外部服务。优先使用明确的章节或概念标签，也识别部分明确的中文定义句。资料无法提供完整概念句或可区分的干扰项时返回原因，不编造试题；实际题数可能小于请求数。

判分仅比较所选选项。练习与首次提交通过 SQLite 持久保存，重复提交不会重复累计，也不能在看过正确答案后覆盖成绩。重新生成练习并答对后，对应概念从待复习列表移除。复习列表按所选资料范围展示，给出错题概念、章节、次数和原文入口。

当前定位的是“这条识记题对应的原文概念与章节”，不是通过语义诊断确认知识盲区；开放式回答判分、先修依赖推断与完整知识掌握模型尚未实现。示例资料生成三道题。操作说明与截图见 [网页说明](local-web.md)。

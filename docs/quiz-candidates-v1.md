# 概念候选与出题检查分离

完成日期：2026-11-05。

这轮完成了候选提取和保守的题目检查，阻止已观察到的七道问题题再次生成。**新的三个章节均为零题，教学质量验收仍未通过。**

## 实现与边界

`quiz_candidates.py` 先记录完整名称、英文别名、原文支持句、文件、页码、章节、提取方式和选项类别，再交给 `quiz.py` 构造题目。命名句中的“隐变量自回归模型”不能被标题或用户指定的“自回归模型”替换。标题只是名称线索，原句还必须有定义、命名、作用说明或明确对比。

题干检查拒绝重复挖空、仍出现的答案或别名、可识别的悬空指代、未展示的图表公式，以及残留的拉丁字符和数学符号。英文别名只在完整名称旁移除，必要条件与完整出处保留。当前不会判断公式中的变量是否已经充分解释，因此会保守拒绝部分本来可用的数学题或英文内容。

干扰项必须来自当前资料和同一识别章节中的合格候选，并具有可识别的同类名称、原文分类或同组编号定义；原文明确排除的对比项也可以使用。取消了按距离用任意概念补齐选项的回退。共同词尾和原文类别仍只是词法线索，不能证明选项语义唯一或难度合适。

候选和题干检查可以分别测试。候选通过提取、甚至通过题干检查，都不表示它已达到教学质量要求。评测报告新增 `candidate_audit`，列出名称、别名、原句、类别、题干拒绝原因和是否最终选用；这些诊断信息不进入作答接口。

# 固定出题诊断评测集 v1

完成日期：2026-11-06。

本轮新增固定语料、标注、锁文件、评测脚本和评测器测试，**未修改五个出题模块**。目标是定位失败阶段，避免继续用几个新章节的题数判断改进。

## 语料与标注

[语料](../eval/quiz-benchmark-v1.json)含 34 个样例：22 个教材样例、12 个人工构造样例。教材输入包含 24 次摘录引用，均核对到所引 PDF 页，教材文件指纹也已验证。相同原句可能用于不同诊断维度，因此这些引用不是独立随机样本。

样例与标签由助手编写，包含已知成功、已知失败和边界情形。这是回顾性、目的性采样；不是未见测试集，不是教师独立评价，也不能估计所有章节的覆盖率。每例附有标注理由，简称采用先出现的完整名称作为规范名。评测只检查标注明确约束的属性，不代替一般语义判断。

四个维度分别测量：

| 维度 | 约束 |
| --- | --- |
| 概念边界 | 预期完整名称集合；漏提取和多提取分别列出 |
| 同义身份 | 明示同义关系、英文别名；缺失关系和错误合并都失败 |
| 上下文 | 应放行或应停止；必要条件、禁用提示和拒绝阶段 |
| 选项与出题 | 必须覆盖的概念组、允许的干扰项、同义去重、答案键和完整原文来源 |

每例等权。一条枚举展开出的三题仍是一个样例；报告另列所要求概念组的覆盖数。返回零题会使正例失败，但能使明确应停止的负例通过。候选缺失与题干检查拒绝分别记录；危险题干即使没有组成最终题目，也会记为误放行。

## 首轮基线

[首次基线](../eval/reports/quiz-benchmark-v1-baseline.json)及[复验报告](../eval/reports/quiz-benchmark-v1-verified.json)的汇总结果一致：

| 维度 | 通过样例 | 比例 |
| --- | ---: | ---: |
| 概念边界 | 6 / 8 | 75% |
| 同义身份 | 4 / 8 | 50% |
| 上下文 | 8 / 9 | 88.9% |
| 选项与出题 | 8 / 9 | 88.9% |

教材样例通过 16/22，构造样例通过 10/12。所要求的概念组覆盖 12/13；这是选定材料中的覆盖，**不是真实教材章节出题率**。四个正向上下文样例通过，另有一个不安全题干被放行。选项维度实际生成的题目中没有违反本集所标约束的题目；这不意味着通用教学质量通过。

[锁文件](../eval/quiz-benchmark-v1.lock.json)在首次计分前固定语料 SHA-256、样例数和工程目标：每维通过率至少 90%，概念组覆盖至少 90%，上下文误放行与不合格题目为零。当前 `passed: false`。这些目标是工程回归要求，不是经实证校准的教学量表。

## 可以直接定位的下一步

1. **先修上下文误放行**：`context-06` 的停用词句仍以“正如我们所看到的”引出未展示的观察。当前没有形成题目，但题干检查已经放行；扩大选项覆盖前应先堵住这个缺口。
2. **补同义身份解析**：`identity-02/04/05/06` 分别暴露定义后的别名、训练数据集／训练集、标签／目标、记忆元／单元。不能把所有“或”一律判为同义，必须保留语境与条件边界。
3. **规范名称与选项类别**：`boundary-04` 只留下简称单元，`boundary-08` 漏掉“所谓缓存命中”的名称；`options-04` 已提取标量与向量、题干检查也放行，但未形成标注允许的区分题。

同一根因可能影响多个维度，所以不能把这八个失败样例当作八个独立缺陷。

## 可复现性与维护

评测脚本是 [evaluate_quiz_benchmark.py](../scripts/evaluate_quiz_benchmark.py)。默认验证语料锁；`--verify-sources` 另核对本地教材指纹和页内原文。报告记录语料、锁文件、评测器和出题模块指纹。没有教材文件时可省略该选项，报告会明确标记本次未验证来源。

输出路径已存在时脚本拒绝覆盖。复跑请使用新的路径，例如：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.evaluate_quiz_benchmark --verify-sources --output .tmp/quiz-benchmark-replay-01.json
```

退出码 0 表示达到本集目标，1 表示未达到；当前预期为 1，并非脚本运行异常。语料指纹不匹配会停止运行。标签修订应发布 v2 并说明原因，不直接改 v1 标签以提高通过率。

评测器的 24 项测试覆盖空输出、错误来源、错误答案键、未批准选项、同义选项、重复身份、缺失条件、危险题干、阶段归因、样例权重和锁文件篡改。全项目 **470 项测试通过**，Ruff 和差异空白检查通过。复验仅加强了对未标注同义关系的错误合并检测及导入格式，汇总与首次基线完全相同。

本轮没有改动页面或出题逻辑，因此没有重复运行浏览器。五个出题模块指纹仍与上一轮冻结记录一致。

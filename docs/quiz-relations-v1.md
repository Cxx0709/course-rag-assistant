# 从原文成组关系生成练习

完成日期：2026-11-06。

本轮让两个此前为零题的章节各产生两道基础识记题。完整原文、页码和成组选项可核对；新的三个未参与修改的章节仍为零题，因此**整体质量与覆盖验收仍未通过**。

## 改动

新增 `quiz_relations.py`，提取两种有明确原文依据的关系：

1. 同一句中的“前者（描述）称为甲，而后者（描述）称为乙”。两题分别使用一项描述，并保留共同适用范围；不把另一项描述展示为提示。
2. 同一段落中的共同对象介绍、控制用途说明，以及连续的“其中一个／另外一个”的功能命名句。题干保留对象介绍和中间上下文，去掉指代顺序词与英文名称；评分反馈保留包含两项功能的完整原文。

关系候选只能使用同组中也通过题干检查的另一成员作为干扰项，不能借用相邻段落、其他页面或另一组的选项。条件、否定和范围不会为增加题量而删除；不符合有界句型的内容继续停止生成。原有普通候选仍按此前的严格规则筛选。

同时修复了上轮审查发现的漏检：单独以“另外一个”开头、没有补齐上下文的题干会被拒绝。

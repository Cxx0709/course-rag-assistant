# v11：过滤 PDF 中明显不完整的回答片段

## 修复的问题

v10 的“深度学习与传统机器学习”回答包含以顿号结尾的截断文字，以及没有后续内容的“下面这样：”。平方误差回答还附带了 PDF 抽取产生的 `l(i)(w, b) = 1`、孤立数字 `2` 和控制字符。引用确实来自教材，并不意味着抽取的片段完整。

v11 在分句之后增加 PDF 候选检查：

- 排除控制字符、括号缺失、没有句末标点的文字，以及以逗号、顿号或冒号结尾的独立片段。
- 保留以分号结束的列表项，以及完整的条件句、否定句和带区间的正文。
- 完整 Python 赋值或调用可不带句号，通过语法解析识别，绝不执行；孤立数字和变量名不作为代码答案。
- 没有完整候选的片段不占用三个回答上下文名额，继续从已经检索并通过证据检查的结果中选取；全部不可用时明确拒答。

同一套候选规则用于模型提示、离线回答、服务故障时的回退，以及最后的引用校验。页码、原始片段、检索索引和原文内容均不改写；不推测缺失的字，不跨页拼接答案。Markdown 和 PPTX 中有意省略句末标点的笔记不应用这项 PDF 规则。

另收紧 v10 的括号换行修复：只拼接中文正文中的括号续行，矩阵输出和完整代码后的换行保留。首轮检查发现普通模式的 Hadamard 积对比题被拒答，原因是旧规则把矩阵输出末行与下一句“不应混淆”的说明拼在一起，导致完整说明随残缺括号被过滤。此问题已加入回归测试。首轮结果保留在 [quality-v11-chat-first-pass.json](../eval/reports/quality-v11-chat-first-pass.json)，不作为最终结果。

## 范围和限制

这是针对抽取结构的保守检查，不是语法、语义或公式正确性判断。带有句号但缺少前文主语的续句仍可能通过；标点完整也不保证与问题相关。PDF 中本来就没有句末标点的简短笔记，以及无法识别为完整语句的数学排版，可能被过滤。冒号引导句不会单独提供给模型，后续完整列表项仍可选择。只有不完整公式而没有文字解释时，应查看原文，系统不会自动补写公式。

## 复现

沿用 [v9 的本机模型配置](answer-completeness-v9.md#使用)，执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_quality.py --dense --chat --chat-rerank --modes hybrid hybrid+chat-rerank --output eval/reports/quality-v11-chat.json
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_quality.py --dense --output eval/reports/quality-v11.json
```

仍使用 30+10 题开发集，标签和参考答案点没有修改；本轮没有独立人工验收。

## 代码验证

181 项测试通过，修改的 Python 文件通过 Ruff。新增覆盖明显截断、控制字符、残缺公式、只有不完整证据时提前拒答、跳过前三个残缺片段后使用后续完整证据，以及普通／模型／模型故障回退三种回答路径。也验证了完整列表项、条件与否定、区间、代码、Markdown／PPTX 无标点笔记、矩阵输出后正文和跨页不拼接。

v4、v5 两组既有回归各 20 / 20 通过，结果分别保存在 [v4 回归报告](../eval/reports/validation-v4-with-v11.json) 和 [v5 回归报告](../eval/reports/validation-v5-with-v11.json)。离线全量报告为 [quality-v11.json](../eval/reports/quality-v11.json)。

两种模式各 30 次答案生成均成功，无整条答案被引用校验拒绝；重排模式 40 次段落选择无异常回退。普通模式中的 Hadamard 积题已恢复为完整的“不应混淆”说明。平方误差题只保留“预测值与实际值之差的平方”的完整解释，不再附带残缺公式；学习率题保留了 `torch.optim.SGD(..., lr=0.03)` 代码。

与 v10 相比，语料、索引、查询缓存、标签和模型配置相同，但 40 次段落选择中有 9 次编号发生变化，不能把全部指标变化归因于过滤规则。未修改题目或评分标准，也未重新挑选较好的一次运行来代替最终结果。

覆盖率下降如实保留：对比题漏选“端到端”，张量题用了“任意数量轴”而非标注中的“任意数量的轴”，循环神经网络题改选了隐状态和历史信息说明。这三题对应的完整原文仍在候选中，需要改善模型选句。卷积网络题本轮进入回答上下文的片段未包含“相近像素”，属于上下文选择差异。梯度下降和 sigmoid 两题新增了字面匹配。半句过滤不等于答案点完整性或语义正确性验收，本轮不宣称整体回答质量全面优于 v10。
